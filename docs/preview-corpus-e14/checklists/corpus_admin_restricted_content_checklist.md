# Corpus Admin Restricted Content Checklist

Date: 2026-06-29

## Before review

- Confirm the row is metadata-only.
- Confirm restricted material remains internal QA only.
- Confirm no source-card, answer-authority, or case-law verification use is proposed.

## Review steps

- Verify authority family.
- Verify source file and source hash.
- Verify restricted display status.
- Verify answer scope.
- Record restricted disposition.
- Record whether license review is needed.
- Record owner escalation for any non-default treatment.

## Default treatment

- No production display.
- No answer authority.
- No source-card display.
- No independent case-law verification.

## Stop conditions

- License approval is absent.
- Owner approval is absent.
- Any restricted row would become displayable, embedded, cited as support, or used in an answer.
