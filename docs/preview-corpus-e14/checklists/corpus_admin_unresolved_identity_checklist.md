# Corpus Admin Unresolved Identity Checklist

Date: 2026-06-29

## Before review

- Confirm the working file is metadata-only.
- Confirm the row comes from the E13-A unresolved identity queues.
- Confirm no legal body text, source text, page text, OCR text, or long excerpt is copied into the register.

## Review steps

- Verify source file.
- Verify source hash.
- Verify authority family.
- Verify document type.
- Verify current display status.
- Verify current answer scope.
- Decide whether identity can be resolved from metadata alone.
- Record proposed action.
- Record decision status.
- Record reviewer role, name, and date.
- Record owner escalation if needed.

## Stop conditions

- Identity depends on filename alone.
- Identity depends on legal body text not available in an approved workflow.
- DCS production-answer authority would be inferred.
- TRE limited scope would be expanded.
- Display eligibility would change.
